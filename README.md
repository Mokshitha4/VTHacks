# FinQuest: Gamified Goal-Based Finance Assistant 🌱�

Welcome to FinQuest! A gamified personal finance tool designed specifically for students that transforms saving and spending decisions into an interactive journey.

## 🎯 Problem Statement

Students often face these financial challenges:
- **Lack financial literacy and guidance** - Don't know where to start with personal finance
- **Decision paralysis** - Don't know which credit card, subscription, or savings strategy is right for them
- **Poor tracking habits** - Struggle to track spending and plan for goals (trips, budgeting, emergency funds)
- **Information overload** - End up making wrong choices or doing nothing due to overwhelming information

## � Solution Overview

FinQuest transforms financial planning into an engaging, game-like experience where users can:
- **Set meaningful goals** (Europe trip, monthly budget, emergency savings)
- **Experiment with recommendations** (cancel Netflix, cut coffee, switch to student Spotify)
- **Visualize outcomes instantly** with "What-if" simulations
- **Track progress and streaks** via subgoals
- **Stay motivated** with a garden-themed gamification system

## ✨ Key Features

### 🎯 Goal Setting Flow
- Interactive goal creation with amount and timeline input
- Multiple AI-generated saving strategies
- Real-time "What-if" simulator showing impact of each choice
- Customizable subgoals that contribute to main objectives

### 🏠 Homepage Dashboard
- **Center**: Active goal progress bar with visual feedback
- **Left**: Complete list of goals with progress and streak tracking
- **Right**: Beautiful garden visualization that grows with your success
- **Bottom**: Quick access to spending visualization tools

### 🤖 Auto-Visualization Agent
- Dynamic analytics of spending categories
- Personalized recommendations based on spending patterns
- Smart suggestions like "You spend a lot on gas → consider XYZ credit card"

### 🎮 Gamification Layer
- **Streaks** make flowers bloom in your garden
- **Achieving subgoals** brings butterflies to your garden
- **Completing main goals** triggers celebration animations

## 🛠️ Technologies Used

### Frontend
- **React** - Modern, component-based UI framework
- **Tailwind CSS** - Utility-first CSS framework for responsive design

### Backend
- **FastAPI/Flask** - High-performance Python web framework

### Data & Integrations
- **Plaid API** - Real transaction data (with mock data fallback for demo)
- **Matplotlib/Plotly** - Advanced data visualization and charting
- **LangChain + LLM** - AI-powered dynamic chart generation

### Gamification & State Management
- **Custom tracking module** - Goal and subgoal progress management


## 📖 Usage

1. **Create Your Account** - Sign up and set up your financial profile
2. **Set Your First Goal** - Choose from templates like "Emergency Fund" or "Dream Vacation"
3. **Explore Strategies** - Use the "What-if" simulator to see different saving approaches
4. **Track Progress** - Watch your garden grow as you hit milestones and maintain streaks
5. **Get Recommendations** - Let our AI agent analyze your spending and suggest optimizations

## 🌟 Unique Value Proposition

- **AI + Gamification Blend** - Unlike plain budgeting apps, FinQuest combines intelligent recommendations with engaging game mechanics
- **Visualization-First Approach** - Users immediately see why a recommendation matters through interactive charts
- **Simple Metaphors** - Garden themes and streaks make finance approachable and fun

## 🎯 Impact

- **Empowers students** to build healthy financial habits early in life
- **Reduces decision fatigue** by providing personalized, actionable steps
- **Makes saving engaging** through gamification and visual feedback
